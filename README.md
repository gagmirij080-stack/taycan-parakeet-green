# Porsche Taycan — Parakeet Green

Ultra-premium dark studio single-page site for a Parakeet Green Porsche Taycan.

Live: https://gagmirij080-stack.github.io/taycan-parakeet-green/

## Run locally

Just open `index.html` in a browser (CDN libs need internet).

## Deploy (GitHub Pages)

Push `main` → Settings → Pages → Deploy from branch → `main` / `/ (root)`.

## Edit contacts

In `index.html`, find the `SITE` object and fill in:

```js
var SITE = {
  whatsapp: '79990000000',
  telegram: 'your_handle',
  phoneHref: 'tel:+79990000000',
  metricaId: ''
};
```

Assets: `1.png`–`5.png` (gallery), `video.mp4` (hero + feature background).
